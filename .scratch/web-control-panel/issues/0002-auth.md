# 0002 — Auth + login/logout

## What to build

End-to-end auth flow:

- Alembic migration tạo bảng `users` (schema theo PRD section "Schema").
- `scripts/create_admin.py` — interactive CLI: prompt username + password (qua `getpass`, hidden), confirm password, tạo user với `is_admin=true`, hash bằng bcrypt. Idempotent: nếu username đã tồn tại, error rõ ràng và không ghi đè.
- `auth_service` (deep module): `hash_password(plain) -> str`, `verify_password(plain, hash) -> bool`, `create_session(user_id) -> session_id`, `resolve_session(session_id) -> User | None`, `destroy_session(session_id)`. Session lưu Redis key `session:{uuid}` TTL 7 ngày, sliding renewal khi resolve.
- FastAPI `SessionMiddleware` đọc cookie `session_id`, attach `request.state.user` (hoặc `None`).
- Routes: `GET /login` (form), `POST /login` (verify + set cookie + redirect home), `POST /logout` (destroy session + clear cookie).
- Template `auth/login.html` extends `base.html`. Hiển thị error inline khi sai credentials.
- 1 protected route example: `GET /` redirect `/login` nếu chưa auth, ngược lại trả homepage placeholder.
- Cookie flags: `HttpOnly=True`, `SameSite=Lax`, **không** `Secure=True` (Tailscale đã encrypt).

## Acceptance criteria

- [ ] `python scripts/create_admin.py` tạo admin thành công, password hash bcrypt, không lưu plaintext.
- [ ] Re-run `create_admin.py` với username đã tồn tại → error rõ ràng, không crash.
- [ ] `GET /` khi chưa auth → 302 redirect `/login`.
- [ ] `POST /login` với credentials đúng → 302 redirect `/`, set cookie `session_id`. Sai → 200 render lại form với error message.
- [ ] `GET /` với cookie hợp lệ → 200 homepage placeholder.
- [ ] `POST /logout` → delete Redis key + clear cookie + redirect `/login`.
- [ ] Session expire sau 7 ngày inactive (verify bằng manual TTL test hoặc unit test với time freeze).
- [ ] Cookie không có flag `Secure` (verify bằng response header).
- [ ] Tests cho `auth_service`: hash khác nhau mỗi lần (salt), verify đúng/sai, session roundtrip, destroyed session không resolve được.
